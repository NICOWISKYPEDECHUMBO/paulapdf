# Programa de Renomear

Lê o nome da pessoa dentro do PDF e renomeia como `DATA NOME.pdf`.

1. Adicione os PDFs (arrastar ou botão).
2. Marque os que quer (ou "Selecionar todos").
3. "Renomear selecionados" → digite a data (ex.: `10 de setembro`) → Renomear.
4. "Baixar selecionados" (vários saem em ZIP).
5. "Apagar selecionados" / "Limpar tudo" para não acumular.

Tudo roda no navegador. Precisa de internet (bibliotecas por CDN).

## GitHub Pages
Suba todos os arquivos na raiz do repositório (incluindo `.nojekyll`). Settings → Pages → branch `main`, pasta `/`.

## Vercel
Importe o repositório, preset **Other**, sem build.
